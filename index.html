SchooledUp

AI-powered student planning application

Course information arrives in many different formats, and students are left to organize it themselves. SchooledUp turns that incoming course information into an organized workspace.

My contribution
Product direction, interface design, and development across the application, using AI coding tools.

Pathfinding & game navigation

Algorithms / Interactive systems

A platformer navigation experiment: build a level, then watch an agent find a route with A*, using jumps, gravity, and collisions. Originally built in Python with py5 and adapted for the browser so you can edit the level and explore the graph yourself.

My contribution
The original Python/py5 project was designed and hand-coded entirely by me, including the navigation graph, pathfinding, agent behaviour, and interactive editor.

Physics simulations

Soft bodies / Collisions / Constraints

A soft-body simulation built from linked points: it falls, deforms, and pushes back toward its original area. Built in Python with py5, with mouse interaction to pull it around.

Related experiments
Ball physics on uneven terrain, then a simple car made by linking two balls together and adding directional controls. Built in Processing’s Python mode.
