Physics / Verlet simulation

One engine,
three bodies.

Soft-body area restoration, a ball on rolling terrain, and a two-wheel car. Drag directly in the canvas, or drive the car with A / D.

This demo requires a browser with Canvas support. A fixed 1/120 s Verlet step drives a soft body, a terrain ball, or a linked two-wheel car.

Soft body running.

Drive

Soft body: drag any point to stretch the ring; the links and area restoration pull it back. Ball: drag the ball and release to let it fall onto the rolling terrain. Car: the two wheels are held at a fixed distance; A / D or ← / → (or the hold buttons on touch) drive along the terrain tangent. Space pauses, R resets. Shortcuts apply only while the canvas is focused; the HUD shows the current mode.

The original Python / py5 experiments were designed and hand-coded entirely by Ryan Fong. This JavaScript / Canvas version is an AI-assisted browser adaptation of that work.

Terrain uses seeded value noise rather than Processing's Perlin noise, so the exact hills intentionally differ; the physics algorithms are ports of the originals.
