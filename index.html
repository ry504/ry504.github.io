SchooledUp

Full-stack product / AI ingestion systems

Problem and product
Course information arrives across documents, slides, recordings and email. I created SchooledUp to bring those inputs into one student workspace: extract deadlines and course information, route them to the right course, and organize them as tasks and source-linked notes.
My contribution
I directed product design and full-stack implementation using AI coding tools. My work spans the Next.js interface, Python/FastAPI backend, course routing and review workflow, with Supabase for application data, authentication and file storage.
Workflow and design choice
Materials in → extracted information → course routing → notes and tasks. Automation handles the first pass; students can review and correct results in the workspace. This adds a review step while keeping extracted information editable.

Pathfinding & game navigation

Algorithms / Interactive systems

A platformer navigation experiment: build a level, then watch an agent find a route with A*, using jumps, gravity, and collisions. Originally built in Python with py5 and adapted for the browser so you can edit the level and explore the graph yourself.

My contribution
The original Python/py5 project was designed and hand-coded entirely by me, including graph generation, A* pathfinding, agent behaviour, and the interactive editor. The browser adaptation was developed with AI assistance.

Physics simulations

Soft bodies / Collisions / Constraints

A soft-body simulation built from linked points: it falls, deforms, and pushes back toward its original area. Built in Python with py5, with mouse interaction to pull it around.

Related experiments
Ball physics on uneven terrain, then a simple car made by linking two balls together and adding directional controls. Built in Processing’s Python mode.
