Algorithms / Game navigation

A route is only
half the problem.

Find a path, then watch an agent walk, jump and fall through it. Change the level to see how the navigation graph responds.

This demo requires a browser with Canvas support. It builds a graph above platforms and uses A* to find routes that the agent attempts with gravity and collisions.

Paint / touch tools

Drag the agent or goal to move them. Left-click / drag paints platforms; right-click / drag erases. Right-click the agent or press Space to run / reset. H toggles the graph; X clears the level. Touch: use Erase to delete. Keyboard: arrows move the cursor, Enter picks up / drops a marker or paints, Delete erases. Shortcuts apply only while the level is focused. Editing resets the agent.

AgentGoalRouteJump link

The original Python / py5 project was designed and hand-coded entirely by Ryan Fong. This JavaScript / Canvas version is an AI-assisted browser adaptation of that work.

The graph estimates reachable movements; some custom levels may produce routes the agent cannot complete. Route curves show connections, not exact flight trajectories.
